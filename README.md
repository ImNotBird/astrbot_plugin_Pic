# 我要看图（astrbot_plugin_Pic）
> 一款面向 AstrBot 的轻量随机图片插件，对接栗次元 API 实现一键取图，内置自动缓存清理机制，开箱即用。

## ✨ 功能特性
- 对接栗次元第三方 API，支持快速获取随机图片
- 图片发送完成后自动删除本地缓存，避免占用磁盘空间
- 发送失败的图片自动留存缓存目录，便于问题排查
- 零复杂配置，安装完成即可直接使用

## 📦 安装部署
### 前置环境
- Python 3.8 及以上版本
- AstrBot 框架可正常运行
- 运行环境具备公网访问能力

### 依赖库

`aiofiles` `requests`

## 🚀 使用方法
### 触发指令
- `我要看图`

### 交互示例
```
用户：我要看图
机器人：好的，正在为你准备图片...
机器人：[图片]
机器人：图片已送达
```

## ⚙️ 补充说明
### 缓存规则
- 正常发送成功的图片，本地缓存会被自动清理
- 发送失败的图片会留存于本地路径`【Astrbot根目录】/astrbot/imgs`

### 接口限制
栗次元 API 存在请求频率约束，约为 5 秒/次，短时间内重复触发可能被限流。
